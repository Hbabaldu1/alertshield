# 🛡️ AlertShield 🇳🇬
### *Instant Dynamic Virtual Account Invoicing, Anti-Fake Alert Engine & Audio Cashier Soundbox for Nigerian Merchants*

AlertShield solves one of the single most painful problems in Nigerian retail & social commerce: **Fake Bank Transfer Alerts and POS Network Downtime**.

Over 70% of retail transactions in Nigeria are direct bank transfers. Merchants lose significant revenues to fake alert SMS apps and bank network delays. AlertShield generates 1-time dynamic 10-digit virtual accounts per sale, monitors the NIP interbank webhook in real-time, and fires a **loud cashier voice alert + branded WhatsApp receipt** in under 2 seconds.

---

## 🚀 Key Features

1. **Cashier Virtual Soundbox:** Instant Web Audio chime and English speech synthesis announcing confirmed payments (*"Alert confirmed! ₦15,000 received from Chidi Okonkwo via OPay"*).
2. **Dynamic 10-Digit Virtual Accounts:** Temporary 1-time accounts (Wema, Providus, Titan Trust) preventing fake receipt scams.
3. **Interactive NIP Transfer Simulator:** Built-in test suite to simulate incoming transfers from OPay, Kuda, GTBank, Zenith, and Moniepoint.
4. **Branded Digital Receipts:** Auto-generated electronic receipts with WhatsApp 1-tap direct share link, print format, and viral watermark loop.
5. **Customer Checkout Page:** Clean mobile-first payment page at `/pay/[id]` with 1-tap copy, countdown timer, and live transfer verification radar.
6. **Direct Auto-Sweep:** Automatic settlement into merchant's real bank account (OPay, GTB, Zenith, Moniepoint).

## 🛠️ Quick Start

```bash
# 1. Navigate to project
cd alertshield

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access the Cashier Soundbox Terminal.
